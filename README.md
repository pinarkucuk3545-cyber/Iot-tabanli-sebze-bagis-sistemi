# Iot-tabanli-sebze-bagis-sistemi
Bu proje; geleneksel ağaç bağışı modellerini dijital ve sürdürülebilir bir tarım ekosistemine dönüştürmeyi amaçlayan IoT Tabanlı Dijital Sera ve Sebze Bağış Platformudur. Bağışçılar platform üzerinden sera ortamında yetişen sebzeleri (ata tohumları dahil) seçerek fide bağışında bulunur. Yetişen ürünler ihtiyaç sahiplerine dağıtılır.
